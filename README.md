 Supply-Chain-Optimization-Dashboard-Excel-
 
  Project Overview
This project focuses on analyzing and optimizing supply chain operations using Microsoft Excel. The dashboard provides insights into product performance, shipping costs, supplier efficiency, and delivery lead times to support data-driven decision-making.

Objective
To identify inefficiencies in the supply chain and provide actionable insights to improve cost efficiency, reduce delays, and optimize overall performance.

Source of data 
Kaggle

Tools & Techniques
- Microsoft Excel  
- Pivot Tables  
- Data Cleaning  
- Data Visualization (Charts & Dashboard Design)  

Dashboard Features
- Stockout Risk Analysis (High, Moderate, Low)  
- Product Profitability Analysis  
- Shipping Cost by Routes  
- Lead Time Analysis by Routes  
- Supplier Performance Analysis  
- Shipping Cost vs Lead Time Comparison  
- Transport Mode Analysis (Air, Rail, Road)  

Key Insights
- A significant number of products fall under moderate to high stockout risk, indicating potential inventory management challenges.  

- Profit generation is concentrated among a few products, while others underperform, highlighting opportunities for product optimization.  

- Route B has the highest shipping cost, while Route C is more cost-efficient, suggesting room for route optimization.  

- Route A shows the longest lead time, which may negatively impact delivery performance and customer satisfaction.  

- Supplier performance varies significantly, with some suppliers contributing to higher costs and longer delivery times.  

- A clear trade-off exists between shipping cost and lead time, requiring strategic decision-making to balance efficiency and cost.  

Recommendations
- Optimize high-cost shipping routes to reduce operational expenses  
- Partner with more efficient suppliers to improve delivery timelines  
- Reassess underperforming products to improve profitability  
- Balance cost and speed when selecting transportation methods
